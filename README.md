# Los Angeles City Attorney Hydee Feldstein Soto Knowingly Files Frivolous Charges As Favor To Scientology
This project contains the case files pertaining to Los Angeles criminal case number 24CJCM03837-01 **People of California v Enri Marini** over a frivolous one count misdemeanor charge of vandalism filed on behalf of Church of Scientology.
